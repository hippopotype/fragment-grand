## Download

Get the zip from [Releases](https://github.com/hippopotype/fragment-grand/releases/latest), or take the files from `fonts/`:

- `fonts/otf/` for Desktop
- `fonts/woff2/` for Web

## Use it on the web

Copy `fonts/woff2/` into your site, then:

```css
@font-face {
  font-family: "Fragment Grand";
  src: url("fonts/woff2/FragmentGrand-Regular.woff2") format("woff2");
  font-weight: 400;
  font-display: swap;
}

@font-face {
  font-family: "Fragment Grand";
  src: url("fonts/woff2/FragmentGrand-Bold.woff2") format("woff2");
  font-weight: 700;
  font-display: swap;
}
```
